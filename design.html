SARVANA ®Studio design reference · November 2026

The existing visual language

Clear direction.
Consistent execution.

An editorial studio identity: bold typography, ink and warm paper, purposeful cyan, generous space and restrained motion.

This guide records the current site's owning sources. It is a guide for future implementation, not a new brand or an alternative palette.

Dark dividers use --line: rgba(241,240,234,.16). Light dividers use the same restrained treatment in ink. Decorative blue light and holographic effects exist in hero artwork; they do not establish new UI accent palettes. Do not invent category-specific greens, pinks or purples.

Typography / layout.tsx

Strong type.
Quiet details.

Production uses Geist Sans for headlines and body, and Geist Mono for small uppercase labels. Both are configured with next/font in the shared layout. There is no separately configured “R” font in the inspected source. Use the approved lowercase Sarvana SVG wordmark from the brand asset folder; do not recreate it with text.

This standalone HTML uses a system sans-serif fallback so it opens offline without fetching or duplicating the Next.js font bundle. The production font source is src/app/layout.tsx.

Headlines: tight tracking, compact line-height, responsive scale. The homepage uses weights from 510 to 760 according to hierarchy; NFC uses the user's requested bolder treatment at 700–730.

Body: 14–20px, comfortable 1.55–1.8 line-height. Labels: 8–11px, uppercase with 0.15–0.2em tracking. Keep text readable on mobile.

Composition

Give each section room.

Chapter rhythm

Alternate paper and ink sections like the homepage. Use generous vertical spacing: roughly clamp(64px, 9vw, 135px), with responsive gutters near 5–6vw.

Editorial hierarchy

Lead with a strong heading and useful copy. Pair media and text in two columns on desktop; stack naturally on mobile. Preserve image proportions and card details.

Minimal controls

Rounded pill actions, small arrow details and thin dividers. Galleries use plain clickable images and an expand icon, without visible collection numbers, design numbers or Preview text.

Actions and motion

Effects with a purpose.

Explore the collection ↗View more ↗

Use brief hover feedback, subtle image scale and one restrained reveal as a section enters view. Existing pages use GSAP and ScrollTrigger. Keep all animation local to its component and clean it up on unmount.

NFC adds the supplied circular image transition, around 0.8 seconds, with manual navigation. Avoid automatic image changes while a visitor is inspecting a card.

Respect prefers-reduced-motion: render content immediately and change images without animated transitions. Never hide essential content permanently if JavaScript or animation fails.

Keep visible focus, 44px touch targets, modal Escape handling, focus restoration, keyboard arrows and mobile swipe. Do not add effects that obscure the cards.

NFC application

One preview.
A complete library.

Catalogue

/nfc shows one card image for each category. A separate View more action opens the dedicated category page. Keep the benefits and purpose clear.

Category library

Offer seamless circular navigation and a simple grid. Clicking an image opens an enlarged viewer with arrows, thumbnails, swipe and selection.

Enquiry only

A selected reference is included in a WhatsApp enquiry. No checkout, cart, invented stock, prices or unsupported promises. Label third-party images as references.

Shared footer

A final connection.

Every page uses the same root-layout ink footer with the existing SARVANA wordmark, Geist typography, navigation and contact links. Two link columns and a founder contact column sit above one oversized muted wordmark. Use the supplied SVG from public/Sarvana_Brand_Assets/01_Wordmark through the shared Wordmark component. Do not duplicate the small logo in the footer. Under that wordmark, a dedicated animated crowd from the supplied reference ends exactly at the copyright divider, inside the same footer. The large illustrated characters use local WebP assets, depth blur and a subtle studio-cyan glow, and never overlap navigation or copyright text. No sample hero, alternate branding or composer is included.

The crowd plays by default without visible controls, using large overlapping characters and quick horizontal movement. Stop animation offscreen and in hidden tabs, and show a still scene for reduced motion. Source: src/components/StudioFooter.tsx, src/components/ui/footer-crowd.tsx and src/app/footer.css.

Shared navigation and service cards.

The root layout owns one floating pill navigation and one footer on every page. At mobile and tablet widths use a keyboard-accessible menu. Service cards use thin borders, quiet surfaces, clear titles and small arrow actions; website services alternate onto paper inside their dedicated service page. The homepage has one FAQ followed by a focused project CTA. Its four process stages occupy one row on desktop. Dedicated service pages alternate ink overview and portfolio sections with paper offering and engagement sections, using actual project screenshots or clearly labelled generated concept imagery. Creative portfolio headings use a smaller responsive scale, a compact hero and a regular work grid; keep interactive text on a solid ink surface.

Sources and maintenance

Where the design lives.

  • src/app/globals.css — studio tokens, navigation, buttons, editorial chapters and shared visual rules.
  • src/app/layout.tsx — Geist Sans and Geist Mono; shared metadata and mobile contact bar.
  • src/app/landing.css — responsive spacing and typography refinements.
  • src/app/volumetric-hero.css, orbit-capabilities.css, creative-folders.css — existing motion and light/dark treatments.
  • src/app/nfc/nfc.css — NFC styles consume these tokens. project.md and AGENTS.md explain architecture and agent instructions.

When an approved design decision changes, update the owning CSS source and this guide together. Do not treat accidental drift as a new brand direction.
