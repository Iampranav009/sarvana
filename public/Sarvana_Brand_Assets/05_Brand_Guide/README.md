# SARVANA • Brand assets
Final identity: lowercase Concept 05 wordmark; Option 02 flowing S favicon.
The SVG artwork is vector-traced from the approved raster concepts, not a font file.
## Palette
- Primary black #000000
- Primary white #FFFFFF
- Optional digital accent #00C8C8 (not part of the primary logo)
- Website dark background #0C0E0F
## Usage
Use black artwork on light surfaces and white artwork on dark surfaces. Transparent PNGs and SVGs are supplied. Favicon names describe foreground color; each uses a contrasting rounded-square background. Use SVG for web and print; use 32px ICO/PNG for browser tabs, 180px for Apple touch, 192/512px for PWA. Use the social icon at 1080px for profiles. Maintain generous clearance around marks. Do not stretch, recolor arbitrarily or add effects.
